# Lyra Embedded for PrestaShop

Lyra Embedded for PrestaShop is an open source plugin that links e-commerce websites based on PrestaShop to Lyra secure payment gateway developed by [Lyra Network](https://www.lyra.com/).

## Installation

To install the module, follow these steps:

- Goto `Modules > Module manager` menu in PrestaShop Back Office.
- Click on `Upload a module` button and select the module ZIP.

## Upgrade

To update the payment module, either follow the installation section or follow these steps:

- Upload `lyra_embedded` directory to `[PRESTASHOP]/modules/` via FTP.
- Goto `Modules > Module manager` menu in PrestaShop Back Office.
- Click on `Upgrade` button corresponding to the Lyra Embedded module entry.

## Configuration

To configure the payment module, click on `Configure` button corresponding to `Lyra Embedded` payment module entry.
